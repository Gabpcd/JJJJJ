## Objectif

Servir nativement le rôle `ADMIN_ETABLISSEMENT` (comptes membres **et** legacy `app_metadata.role = 'ETABLISSEMENT'`) pour le travail de terrain : actions prioritaires, missions, candidatures, pointage (code rotatif + QR plein écran sans veille), validation/contestation des présences, contrats + OTP, messagerie, publication d'une mission simple ou urgente. Tout le reste (facturation, SEPA, Chorus, RH, export paie, équipe, API, litiges, évaluations, annuaire, récurrence avancée, libéral) est un renvoi web explicite. Aucune règle juridique ni montant n'est calculé côté client ; les droits viennent de `fn_mes_permissions_etab` (l.42265) aux 11 clés réelles de `src/hooks/useEtabPermissions.ts` l.7-19.
